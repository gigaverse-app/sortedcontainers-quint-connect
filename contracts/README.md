# Quint contracts

Model-based tests for sortedcontainers, run with
[pytest-quint-connect](https://github.com/gigaverse-app/pytest-quint-connect). Each contract is a
small Quint model of one API; pytest replays histories generated from the model against the real
code, and planted bugs (mutants) prove that the check can fail.

- `sorted_list/sorted_list.qnt` is the specification of `SortedList` to review.
- Run locally with `tox -e contracts` (needs Node.js 22+; the plugin installs Quint on first use).
